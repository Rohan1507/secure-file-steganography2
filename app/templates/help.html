How Secure File Sharing with Steganography works

What is steganography?

Steganography is the practice of concealing a message, file, or data inside another, non-secret file so that its existence itself is hidden. Unlike encryption, which scrambles data into unreadable ciphertext (but still reveals that a secret exists), steganography hides data in plain sight — for example, inside the pixels of a photograph.

What is LSB (Least Significant Bit) steganography?

Every pixel in a digital image is made of color channels (Red, Green, Blue), each stored as a byte (0–255). The "least significant bit" is the smallest, right-most bit of that byte — changing it shifts the color value by at most 1 out of 255, an amount invisible to the human eye. By replacing the LSB of many pixel channels with the bits of a secret message, we can hide a substantial amount of data inside an image without visibly altering it.

How does this application secure your files?

  1. Your secret file is read as raw binary data.
  2. It is encrypted with AES-256-GCM, using a key derived from your password via PBKDF2-HMAC-SHA256. GCM mode provides both confidentiality and built-in integrity/authentication (a forged or corrupted ciphertext will fail to decrypt).
  3. The encrypted data, plus metadata needed to reconstruct it (filename, extension, salt, nonce, SHA-256 hash), is packed into a structured binary payload.
  4. That payload is embedded into a cover image's pixels using LSB substitution, producing a "stego image" that looks identical to the original at a glance.
  5. The receiver uploads the stego image, the app extracts the payload bits, and — with the correct password — decrypts and verifies the file against its original SHA-256 hash before allowing download.

Security Disclaimer

  • Steganography hides the existence of information; it does not replace encryption. This app always encrypts first.
  • LSB steganography can be vulnerable to statistical steganalysis (see the Security Analysis page) and is destroyed by lossy transformations like re-saving as JPEG, resizing, or heavy compression.
  • PNG and BMP are the only supported cover formats in this project, because they are lossless — JPEG compression would corrupt the hidden bits.
  • This project is intended for educational and authorized file-sharing demonstrations. It makes no claim of being 100% undetectable, unbreakable, or "military-grade" — no steganographic or cryptographic system can honestly claim that.

Supported file types

Cover / stego images: PNG, BMP.

Secret files: any binary or text file — TXT, PDF, DOCX, XLSX, ZIP, images, MP3, MP4, and more. The file is treated as raw binary data, so byte-for-byte integrity is preserved and verified via SHA-256.

Audio (optional module): WAV (16-bit PCM) is supported as a secondary carrier format using the same LSB approach on audio samples. Compressed audio (MP3) is not supported, since lossy compression destroys LSB data the same way JPEG does for images.
