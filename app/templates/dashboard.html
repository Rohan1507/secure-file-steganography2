Security Notes

This project uses AES-256-GCM for authenticated encryption and LSB steganography for concealment. PNG/BMP are the only supported cover formats because lossy compression (like JPEG) destroys hidden LSB data. Steganography hides the existence of information — it does not replace encryption, which is why both are used together here.
