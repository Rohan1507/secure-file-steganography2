SECURE FILE SHARING WITH STEGANOGRAPHY
=======================================

This is a sample secret file used to demonstrate the complete
encryption -> LSB embedding -> extraction -> decryption pipeline.

If you can read this after extracting it from a stego image,
the entire system is working correctly end-to-end.

Try embedding this file into sample_cover.png with a password,
then extract it back out and compare the SHA-256 hashes.
